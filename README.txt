SAVINGSFUEL v1.5 — iOS / PWA EDITION

WHAT THIS VERSION DOES
- iPhone/iPad responsive layout
- Home Screen web-app metadata and icon
- Standalone app-style display when installed from Safari
- Offline app-shell caching when hosted over HTTPS
- Savings Tanks persist on the device using browser storage
- Touch-friendly drag/reorder controls
- Existing dashboard/setup/editor navigation retained

IMPORTANT
A Progressive Web App cannot be fully installed from a local file:// URL.
To use the PWA features, host this folder at an HTTPS web address, then open
index.html in Safari on the iPhone and use Share -> Add to Home Screen.

The HTML itself can still be opened locally for desktop testing.
